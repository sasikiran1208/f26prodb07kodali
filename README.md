# f26pro07kodali

Web Applications Assignment 10

## Description
An Express.js web application using the Pug template engine to generate dynamic web pages.

## Technologies
- Node.js
- Express.js
- Pug
- HTML and CSS

## Run Locally
1. Install dependencies using `npm install`.
2. Start the server using `npm start`.
3. Open `http://localhost:3000` in a browser.

## Resource Class: Gardens

The resource class selected for this assignment is Gardens.

Attributes:
- name (String): Name of the garden
- location (String): Location of the garden
- areaAcres (Number): Garden area in acres
- yearOpened (Number): Year the garden opened
